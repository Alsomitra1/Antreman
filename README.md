# Antrenman — 5 Gün Yağ Yakım Planı

Haftada 5 gün, yağ yakımı odaklı antrenman programı. Telefondan açılır, uygulama olarak kurulabilir.

- Her hareket için başlangıç ve bitiş fotoğrafı
- Beğenmediğin hareketi aynı kası çalıştıran alternatiflerle değiştirme
- Set işaretleme ve otomatik dinlenme sayacı
- İnternetsiz çalışır (PWA)

Hareket fotoğrafları: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) — kamu malı (Unlicense).
